# 🌹 Projeto Roberta — Um Site de Amor

Este é um projeto web frontal (Front-End) desenvolvido como uma homenagem romântica e personalizada. O site combina um design sofisticado e clássico com interações modernas, criando uma narrativa visual para celebrar momentos especiais.

---

## ✨ Funcionalidades e Diferenciais

* **Experiência Visual Imersiva:** Efeito de partículas flutuantes dinâmicas utilizando a API Canvas do HTML5.
* **Interatividade Avançada:** Cursor customizado e interativo que reage aos movimentos do usuário.
* **Animações Fluídas:** Transições de revelação de conteúdo baseadas na rolagem da página (utilizando *Intersection Observer*).
* **Navegação Inteligente:** Menu responsivo adaptado para dispositivos móveis e rolagem suave (*smooth scroll*).
* **Seções Especiais:** Janelas modais interativas para mensagens surpresas e galeria/histórico dedicada.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído puramente com tecnologias web nativas, prezando pelo desempenho e leveza:

* **HTML5:** Estruturação semântica das páginas (`index.html`, `sobre.html`, `nos.html`).
* **CSS3 Avançado:** Utilização de variáveis globais (`:root`), flexbox, grid layout, animações personalizadas (`@keyframes`) e total responsividade para celulares e desktops.
* **JavaScript (Vanilla):** Lógica nativa para manipulação do DOM, efeitos de animação, controle do canvas de partículas e comportamento dos componentes interativos.
* **Google Fonts:** Tipografia refinada utilizando as famílias *Playfair Display*, *Crimson Text* e *Cormorant Garamond*.
