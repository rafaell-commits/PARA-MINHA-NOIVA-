Sobre este site

Criado com cada coisa que aprendi — para você

Este projeto carrega todo o meu aprendizado e, mais do que isso, cada linha de código foi escrita com você em mente. Cada cor escolhida, cada palavra selecionada — tudo pensado para te fazer sorrir.

Você merece o melhor de mim em todos os sentidos. E se hoje o que tenho a oferecer é código, então que seja o mais bonito código do mundo.

"Amar é encontrar na felicidade de outro a própria felicidade."

— Gottfried Wilhelm Leibniz

Nossa relação não é perfeita — e nem precisa ser. É real, é quente, é nossa. Cada momento ao seu lado vale mais do que qualquer verso que eu possa escrever.

Mas como gosto de escrever, decidi criar este lugar: um canto digital só para você, para que você saiba — onde quer que eu esteja — o quanto você importa.
